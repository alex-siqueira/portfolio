{%- comment -%} Ícones do site, sem dependência externa. {% include icon.html name="github" size="18" %} {% include icon.html name="menu" size="22" class="menu-toggle__open" %} Parâmetros: name (obrigatório), size, class. Sempre passe `size` explicitamente. Liquid expõe `size` como propriedade mágica de qualquer hash — inclusive do hash de parâmetros de um include — então quando `size` não é passado, `include.size` não vira nil: vira a contagem de parâmetros que FORAM passados (github chamado só com `name` retorna include.size = 1). O fallback `default: 24` abaixo só dispara quando o include não recebe parâmetro nenhum, então nunca protege uma chamada real. Todo call site do repo passa `size=` por isso. O tamanho real de cada ícone vem do CSS (.nav-icon svg, .info-list__item svg, .footer__social a svg, e assim por diante) — o width/height daqui é só o valor de partida. Ícones de traço no mesmo desenho do restante da interface. Os de marca (github, linkedin, youtube) vivem aqui porque o lucide os removeu na linha 1.x; não adianta procurá-los numa versão nova da biblioteca. {%- endcomment -%} {%- assign size = include.size | default: 24 -%}
